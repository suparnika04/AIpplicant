# AIpplicant 🤖

AIpplicant is an AI-powered resume analysis and candidate ranking platform designed to simplify the recruitment process for both job applicants and recruiters.

The platform provides two main experiences:

👩‍💻 APPLICANT

Applicants can upload their resume and enter a desired job role to analyze how well their resume matches the requirements of the role. AIpplicant evaluates the resume and provides an ATS compatibility score along with a resume summary, helping applicants understand their resume strength and improve their chances of getting shortlisted.

👨‍💼 RECRUITER

Recruiters can upload job descriptions and multiple candidate resumes to evaluate candidates for a particular role. AIpplicant analyzes the resumes against the selected job requirements and ranks candidates based on their relevance, helping recruiters identify the most suitable candidates more efficiently.

✨ KEY FEATURES

• Resume upload and analysis
• Job-role-based resume matching
• ATS compatibility scoring
• AI-generated resume summary
• Candidate ranking for recruiters
• Multiple candidate resume analysis
• Job description-based candidate evaluation
• Separate applicant and recruiter workflows
• Simple and user-friendly interface

Upload Resume → Enter Job Role → Resume Analysis → ATS Score → Resume Summary

For Recruiters:

Upload Job Description → Upload Candidate Resumes → Select Job Role → Resume Analysis → Candidate Ranking → Identify Best Candidates

🎯 OBJECTIVE

The main objective of AIpplicant is to make the resume screening process faster, simpler, and more effective.

For applicants, the platform provides insights into how well their resume matches a particular job role and helps them understand their ATS compatibility.

For recruiters, AIpplicant reduces the effort required for manually screening multiple resumes by analyzing and ranking candidates according to job requirements.

⚙️ INSTALLATION & SETUP

1. Clone the Repository

       git clone https://github.com/suparnika04/AIpplicant.git

2. Navigate to the Project Directory

       cd AIpplicant

3. Create a Virtual Environment

       python -m venv venv

4. Activate the Virtual Environment

For Windows:

       venv\Scripts\activate

For macOS/Linux:

       source venv/bin/activate

5. Install the Required Dependencies

       pip install -r requirements.txt

▶️ RUN THE APPLICATION

Start the application using:

       streamlit run frontend.py

The application will open in your default web browser.
